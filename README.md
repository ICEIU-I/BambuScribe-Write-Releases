# BambuScribe Write 下载

[下载 macOS 版 0.1.6](https://github.com/ICEIU-I/BambuScribe-Write-Releases/releases/tag/v0.1.6)

适用于 M 系列 Mac，macOS 13 及以上。打开 DMG，将应用拖入 Applications。

0.1.6 新增多图数据处理导入、可编辑上下分式和默认 20% 的手写变化，每页结束采用高位回程。0.1.1 及以上版本可在应用内点击“检查更新”升级；已上传的页面需重新上传。

安装帮助见安装包内 `安装说明.txt`；[历史版本](https://github.com/ICEIU-I/BambuScribe-Write-Releases/releases)。
