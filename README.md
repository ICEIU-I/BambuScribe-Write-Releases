# BambuScribe Write 下载

[下载 macOS 版 0.1.7](https://github.com/ICEIU-I/BambuScribe-Write-Releases/releases/tag/v0.1.7)

适用于 M 系列 Mac，macOS 13 及以上。打开 DMG，将应用拖入 Applications。

0.1.7 修复表格手动缩放和识别提示反复出现，改进多图智能导入、公式表格、正文预览及 Tab 缩进。0.1.1 及以上版本可在应用内点击“检查更新”升级；如需应用新的笔迹与排版，请重新生成并上传页面。

安装帮助见安装包内 `安装说明.txt`；[历史版本](https://github.com/ICEIU-I/BambuScribe-Write-Releases/releases)。
